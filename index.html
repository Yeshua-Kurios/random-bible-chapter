          Backup & restore

          This app only stores progress in this browser. If you're using it as a home-screen app, iOS can occasionally clear that storage on its own — save a backup code now and then (e.g. into Notes) so you can restore your progress, level, and completions if that happens.

          Reading log sync & cloud backup

          Paste a GitHub personal access token (fine-grained, scoped only to your private reading-log repo's Contents permission) to send each chapter you mark as read there automatically. This token is stored only in this browser (localStorage) — it isn't part of the app's source code.

          With a token saved, your full progress — history, level, achievements, streak freezes, and trivia progress — is also backed up to your private repo after every chapter. If this browser ever loses its data, paste your token again above and tap Restore from cloud. A backup is never overwritten by a device that has less progress than it.
